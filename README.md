# Item Speedrun (Fabric, Minecraft 26.3)

Спидран добычи случайного предмета: колесо предметов перед созданием мира, усложнения,
секундомер с иконкой, статистика и сид мира в чате. Работает в хардкоре.

## Как играть

### Перед созданием мира
1. Заполни настройки мира и нажми **«Создать новый мир»**.
2. Игра спросит **«Начать спидран предмета?»**. «Нет» - мир создаётся как обычно.
3. «Да» - прокрутится колесо с предметами, остановится на твоей цели, нажми «Далее».
4. Игра спросит **«Поставить усложнение?»**. «Да» - прокрутится колесо усложнений.
5. Мир создаётся, через ~3 секунды после входа в чате появится **сид мира**, запустится секундомер.
Esc на любом окне возвращает на экран создания мира.

### Внутри мира (команды, права оператора не нужны)
| Команда | Что делает |
|---|---|
| `/itemrun` | забег без усложнения |
| `/itemrun hard` | забег со случайным усложнением |
| `/itemrun challenge <id>` | забег с выбранным усложнением |
| `/itemrun challenges` | список усложнений с id |
| `/itemrun reroll` | другой предмет (усложнение сохраняется) |
| `/itemrun cancel` | отмена (в статистику не идёт) |
| `/itemrun stats` | статистика |

## Секундомер
Вверху по центру: иконка предмета, время `мм:сс.мс`, название цели и усложнения.
Останавливается, когда предмет попал в инвентарь (хотбар, инвентарь, броня, вторая рука).

## Усложнения (35 штук, нарушение = смерть)
- **Движение:** без прыжков, без бега, без приседания, не стой на месте (15 с), марафонец (бежать каждые 20 с),
  кузнечик (прыгать каждые 12 с), вода - лава, привязанный (до 200 блоков от старта),
  низкий полёт (не выше +15), мелководье (не глубже -15).
- **Время:** 5, 10 или 20 минут.
- **Здоровье:** хрупкое стекло (любой урон), без лечения, голодовка, бессонница, без опыта.
- **Инвентарь:** без кирок / мечей / топоров / факелов / верстака / печей, голые руки (никаких инструментов),
  деревянный век, голышом (без брони), тесные карманы (только хотбар), минималист (не больше 6 слотов).
- **Мир:** только Верхний мир, под небом (не прятаться без неба >20 с), пещерный житель (не быть на солнце >30 с).
- **Дальний старт:** случайная точка примерно в 1500 / 5000 / 12000 блоках от спавна.

Первые 2 секунды после старта усложнения не проверяются.

## Статистика
После каждого забега в чат выводится:
- **Рекорды** - 3 самых быстрых удачных забега;
- **Антирекорды** - 3 самых медленных удачных забега;
- **Удачи** - сколько забегов завершено без смерти;
- **Неудачи** - сколько закончилось смертью (в том числе из-за усложнения).

Данные хранятся в `config/itemspeedrun-stats.json` (общие для всех миров). Отмена командой не считается.

## Сид
Сразу после загрузки мира в чат пишется сид (только в одиночной игре).

## Чёрный список предметов
`config/itemspeedrun-blacklist.txt` - по одному id в строке (например `minecraft:sponge`), если выпал предмет, который нельзя добыть в выживании.

## Сборка
Нужны JDK 25 и Gradle 9.5+, либо сборка через GitHub Actions (файл `.github/workflows/build.yml`).
Готовый мод: `build/libs/itemspeedrun-1.1.0.jar` (без `-sources`). Нужны Fabric Loader 0.19.5+ и Fabric API для 26.3.
